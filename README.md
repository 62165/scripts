# scripts

This folder contains scripts.

## Scripts

| Folder | Description |
|--------|-------------|
| `file_copy` | Copies folders from a source location to a destination location using a CSV list of folder names. |
| `tautulli_scripts` | Contains Tautulli-related helper scripts, including a report that queries the Tautulli API to show encrypted versus unencrypted users and clients. |
| `updateubuntu` | Runs an Ansible playbook to update Debian/Ubuntu systems, upgrade packages, and reboot if needed. |
